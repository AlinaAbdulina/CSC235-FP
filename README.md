## Purpose of the VA System

This project is a visual analytics system designed to help explore environmental and macroinvertebrate data collected in the Mill River upstream and downstream of Paradise Pond. The goal of the system is to help users compare conditions across locations and investigate how sediment redistribution in Paradise Pond may relate to changes in river conditions and biological groups.

The current prototype focuses on three linked views:
- **Graph 1:** pH and feeding groups
- **Graph 2:** Conductivity and feeding groups
- **Graph 3:** Flow and feeding groups

These views are designed to support comparison between:
- **Upstream vs. downstream**
- **Different feeding groups**
- **Environmental variables connected to macroinvertebrate patterns**

## How to Use the System

1. Open the website in a browser.
2. Scroll to the **Visualization plan** section.
3. Use the **feeding group dropdown** to filter the graphs by one feeding group or view all groups.
4. Click a point in any graph to highlight that feeding group across all three graphs.
5. Click the same point again to reset the selection back to the default view.
6. Read the graph notes below each chart for context on what each view is meant to show.
